# 奇妙匣 · 内置工具箱大全

手机端优先的**原创内置工具**集合，点开即用，不跳转外部网站。

## 已实现（30+）

- 开发：二维码生成/解析、JSON 格式化、正则测试、Base64、URL 编解码、哈希计算、JWT 解析、时间戳、UUID、Linux 命令速查
- 办公：字数统计、文本对比、颜色工具
- 专注：番茄钟、待办清单、白噪声
- 日常：密码生成、计分板、尺子、万年历、来电模拟
- 生活：BMI、纪念日、垃圾分类、网络信息
- 趣味：LED 弹幕、藏头诗、彩虹屁、答案之书、疯狂星期四、渣男语录、舔狗日记、脑洞问题、摩斯电码

## 开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
npm run preview
```
